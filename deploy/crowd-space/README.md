# Mohammad Crowd Detection

Interactive crowd counting demo extracted from the Stage 2 notebook.

The app exposes:

- image upload
- density-map inference
- crowd count estimation
- heatmap overlay
- peak proposal visualization
- baseline vs advanced metric context

Training data, density caches, virtual environments, and full experiment output folders are excluded.
